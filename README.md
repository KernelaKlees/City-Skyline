# 🌆 City Skyline

A simple **City Skyline** project created as part of the freeCodeCamp Responsive Web Design curriculum.  
The page uses basic shapes, gradients, and layout techniques to build a stylised skyline scene.

## ✨ Features
- 🏙️ Stylised skyline made with pure CSS  
- 🎨 Gradients and colour layering  
- 📐 Simple responsive layout  
- 🧱 No images — only HTML & CSS  

## 📌 Status
Project completed for practice.  
Can be expanded with animations or additional layers.

## 🛠️ Technologies
- HTML  
- CSS  

## 📚 Lessons Learned
- 🎨 How to use gradients to create depth  
- 🧱 How to build shapes using CSS only  
- 🏗️ How layering works in CSS (z-index)  
- 📐 Basics of responsive positioning  

## ⏳ Future Improvements

- ✨ Add simple CSS animations (lights turning on/off)  
- 🏢 Add more building shapes  
- 🌅 Add a sunrise/sunset gradient transition
